⚙️  TROUBLESHOOTING:

  If backend won't start:
    → Check port 8000 is free: netstat -ano | findstr :8000
    → Kill process if needed: taskkill /PID <pid> /F
    → Try: python -m uvicorn main:app --reload

  If frontend won't start:
    → Clear node_modules: rm -r node_modules && npm install
    → Check port 5173: lsof -i :5173 (macOS/Linux)

  API connection issues:
    → Check VITE_API_URL in frontend/.env = http://localhost:8000
    → Verify CORS headers in backend (main.py)
    → Check browser Network tab for 503/404 errors
